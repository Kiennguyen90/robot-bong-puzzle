# Robot Bông Puzzle

Game xếp hình kết hợp đấu robo 12 con giáp, 6 hệ (Kim · Mộc · Thủy · Hỏa · Thổ · Lôi).

- **Hành trình 6 hệ**: chơi với máy lần lượt qua 6 vùng đất theo vòng tương khắc; map cuối là hệ khắc chế con giáp bạn chọn.
- Thẻ bài mở ngay từ ván đầu.

## Chạy

Mở `index.html` bằng trình duyệt (hoặc chạy một web server tĩnh trong thư mục này). Nếu tải về dạng zip, hãy giải nén trước khi mở.
